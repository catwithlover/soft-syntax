# Website Fonts

`Quicksand[wght].ttf` is the unmodified upstream Quicksand variable font. Its license is included in `Quicksand-OFL.txt`.

`SoftSyntaxRoundedTC-subset.woff2` is a WOFF2 subset derived from the bundled jf open huninn 2.1 source for the Traditional Chinese website. Subsetting and format conversion make it a Modified Version under SIL Open Font License 1.1, so its user-facing names are:

- Family: `Soft Syntax Rounded TC`
- Full name: `Soft Syntax Rounded TC Regular`
- PostScript name: `SoftSyntaxRoundedTC-Regular`

The modified font does not use the Reserved Font Names `open huninn` or `huninn` as its primary font name. Original copyright and license metadata remain in the font for attribution. The complete Huninn OFL and Kosugi Maru Apache-2.0 notices are published under `/licenses/fonts/huninn/` by the Pages workflow.

The subset contains the glyphs used by `site/zh-TW/index.html` and the localized copy feedback in `site/script.js`. Regenerate it whenever that text gains new characters.
